## 发现并解决的问题

- Windows 下 `upload.ts` 与 `Upload.tsx` 导入解析发生文件名大小写冲突，上传请求模块改为 `upload-image.ts`。
- 初次 PNG 测试样本校验不通过，真实后端拒绝 400；替换为真实图片编码器生成的有效 PNG，重新验证普通 / 照片上传通过。
- 原生包裹式 label 把选择框选项及提示文字混入名称，改用独立标签与明确的 aria-labelledby / aria-describedby。
- 测试等待条件加入页面分页元数据、列表已加载和同步按钮可用状态，避免把异步加载竞态误判为产品失败。
- 超时测试的浏览器上下文不能可靠执行清理，夹具增加容器内独立清理；先前失败运行的显式临时记录已清理，并在最终测试验证原始数量与字段。
- 主包最初包含 Markdown 解析器，改为按需加载编辑预览。
